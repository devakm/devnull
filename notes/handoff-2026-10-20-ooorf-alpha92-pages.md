## Rules the user set (enforce)

- **No metaphor, no figurative wording, no invented details.** Plain literal facts only. See memory
  `feedback_no_metaphor.md` for rejected examples. Translate pipeline jargon ("gate", "knob",
  "ownership declaration", "lane") into plain words. Never write "the people OOORF stands on";
  "stands on the work of" is acceptable.
- **In-game names on player-facing pages, never set IDs.** Overview text and both galleries use
  in-game names (Arctic Fur, Jephre's Aureus, The Bear's Armor, Dark Malachite Plated, Draconis Family,
  Imago Storm's Armor, "Gray Fox's Armor of Deception and Gray Fox's Armor of War"). Set IDs appear only
  in `<code>` file names, URL anchors, and New Items' small "(<SetId> set based on <base>)" tag.
- **Images are the user's in-game screenshots** (never "renders"), from ItemClone
  `original/UE5_OOO_ArmorReference/` and `UE5_OOO_WeaponReferences/`. Full-body only — prefer the latest
  `-shadows` shot; sunlight for ElvenEldar, Jephre's Aureus, Draconis, Golden Bronze, and when shadows is
  too dark. Version numbers in file names are the user's guesses: rename to the set's latest version in the
  user's own sequence (Noble's latest is v52; the lone `v84` file is a typo). Crop the site copy if the
  shot is framed too wide; never edit the user's original.
- **Credits:** donor sets say "New items created from the Glass replacer *<title>* by <creator>"
  (Obsidian, Blue Glass, Dark Malachite); Drakefired says "New items using Red glass mod of *Blackened
  Steel Glass Armor and Weapons* replacer by ProhagonCreations". In-house sets say "New armor set created by
  devakm with inspiration from classic OOO artists." (Light of Dawn: "New weapon …"). Sets that never
  existed in classic OOO (the three Ancestral sets) say just "New armor set created by devakm." and carry
  a "New in OOORF" tag.
- **Light of Dawn:** the four in-game swords are `WeapLightOfDawnFlame` (tainted), `FlameA` (initial
  restoration stage), `FlameB` (intermediate), `FlameC` (fully restored at 300 vampire kills). The

- **Ancient Mithril weapons** is the in-game name; "Royal" is only in the EditorIDs.
- Merges create a merge commit (`merge.ff=false`); no Claude co-author trailers.
